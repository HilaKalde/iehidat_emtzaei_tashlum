# חדר כושר פיננסי – יחידת אמצעי תשלום (HTML)

לומדת HTML של בנק ישראל – חינוך פיננסי, יחידת אמצעי תשלום. גרסת עבודה לבדיקה לפני המרה ל-Storyline.

## הרצה
פותחים את `index.html` בדפדפן (Chrome / Edge).
עדיף להריץ דרך שרת מקומי – כך ספירת החזרות בקרוספיט מדויקת וסרטוני יוטיוב מתנגנים בתוך הלומדה.

## מבנה
- `js/data.js` – כל התוכן (מקור אמת יחיד): מסכים, שאלות, תשובות, משובים, קישורים, תסריטי סרטונים.
- `js/app.js` – מנוע הלומדה: במה קבועה 1200×675, מסך = `.screen`.
- `css/style.css` – סגנון הבסיס (משותף ליחידת ריבית), `css/payments.css` – רכיבים ייעודיים ליחידה.
- `assets/` – רקעים, דמויות, אייקונים, פונטים, סאונד ווידאו.

## כלי בדיקה (מחוץ לבמה)
רשימת מעבר לכל מסך, כפתור "📝 הערות" (או מקש N) – הערות הפקה ותסריטי הסרטונים, וכפתור איפוס התקדמות.
